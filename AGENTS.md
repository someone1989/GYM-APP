# GYM-APP - Project Context

## What it is
GymClimb v6.0 - gym, climbing, hiking, running, yoga, smartwatch, weather tracker. Single HTML file PWA (no server, no signup, data stays on device). Multilingual (EN/HR/DE).

## Language
HTML (single-file app: HTML + CSS + JS inline)

## Build / Run
- No build step - open `index.html` in browser
- PWA: add to home screen (Safari/Chrome)
- Demo data: `gymclimb-demo-data.json`

## Deploy
- GitHub Pages (public repo)
- Push `index.html` to main -> live on Pages

## Notes
- One file: `index.html` (~174KB, everything inline)
- Languages: English, Hrvatski, Deutsch (Settings -> Language)
- Settings: name, city, smartwatch, language
- Data is local-only (localStorage), no backend
